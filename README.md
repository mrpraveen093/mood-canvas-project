# 🎨 Mood Canvas – Emotion Reactive

Mood Canvas is a web application that helps users explore and express their emotions through an interactive, user-friendly digital experience.

## ✨ Features

- 🎭 Emotion analysis and visualization
- 🎨 Interactive and responsive user interface
- 🔐 User authentication (if implemented)
- 📊 Emotion results and history (if implemented)
- 🗄️ MongoDB database integration
- ⚡ REST API built with Node.js and Express

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- CSS

**Backend**
- Node.js
- Express.js
- REST API

**Database**
- MongoDB

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Install dependencies

Open the frontend and backend folders in separate terminals and run:

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file in the backend folder and configure your MongoDB connection string and other required environment variables.

**Never upload passwords, database credentials, or secret API keys to GitHub.**

### 4. Run the application

Start the frontend and backend using the development scripts defined in their respective `package.json` files.
